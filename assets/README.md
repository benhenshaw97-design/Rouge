# Art Assets

Put art assets for Rouge in this folder.

| Folder         | What goes here                                  |
|----------------|-------------------------------------------------|
| `sprites/`     | Characters, enemies, items, and tiles           |
| `backgrounds/` | Backgrounds, maps, and environment art          |
| `ui/`          | Icons, buttons, fonts, and HUD elements         |
| `audio/`       | Sound effects and music                         |

## Uploading on GitHub
1. Open the subfolder you want, such as `assets/sprites`.
2. Click **Add file → Upload files**.
3. Drag your files in and click **Commit changes**.

Lowercase file names with dashes work best, for example `player-idle.png`.
