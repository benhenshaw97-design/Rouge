# Sound effect sources

The game uses trimmed, level-matched copies of these in `assets/audio/`.

| Game sound | Source |
|---|---|
| `chuff.wav` | `623817__birdofthenorth__single-steam-train-chuff.wav` (Freesound, birdofthenorth): trimmed to 0.45 s with a fade |
| `whistle.wav` | `soundsgoodmusic-train-whistle-306031.mp3`: levelled up, faded out |
| `brake.wav` | `ElevenLabs_Subway_train_brake_screech.mp3`: trimmed to 1.6 s, faded, turned down |
| `coins.wav` | Kenney Casino Audio, `chips-stack-3.ogg` (CC0) |
| `click.wav` | Kenney UI Audio, `click1.ogg` (CC0) |
| `switch.wav` | Kenney UI Audio, `switch3.ogg` (CC0), used for the junction points |
| `warning.wav` | Kenney Interface Sounds, `error_006.ogg` (CC0) |

Not used yet: `freesound_community-steam-train-sound-effect-71076.mp3` (a 37 s recording). Its
chuffs have their own rhythm, which would clash with the game's chuffs that follow the wheels.
It could work as background ambience at stations.

Check the licence of each Freesound / Pixabay / ElevenLabs file before publishing the game
commercially; some Freesound sounds require attribution.
